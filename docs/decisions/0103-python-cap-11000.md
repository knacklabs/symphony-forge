# Forge's Python cap is 11,000

## Context

On 2026-10-05 Forge's Python reached its 10,000-line cap. The two-lanes story and the Claude Code
mod story still have several parts to add, and two changes already stopped on the cap (the mod's
machine views needed 248 more lines, review during CI 14).

## Decision

The cap still counts only Python files under `src/forge`, and it is 11,000. The owner chose this
on 2026-10-05 over a trim pass first and over trimming inside each feature, together with the
hotspot simplify fixes `forge next` names (close.py, codex.py, the fast test picker, Forge's CI
workflow), each of which must cut lines.

## Consequences

Features keep moving. The cap stays a pressure toward simple code: the next raise needs another
accepted decision.
