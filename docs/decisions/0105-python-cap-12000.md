# Forge's Python cap is 12,000 for the release

## Context

Forge's 11,000-line Python ceiling blocks the live-status, lanes and lookup work from landing.
The owner chose to raise the ceiling rather than trim inside those features.

## Decision

Raise the ceiling to 12,000 Python lines under `src/forge`. The owner chose this on 2026-10-07.
After the release, run simplify fixes for the files Forge flags as keeps-breaking. Each fix must
cut lines, aiming to bring Forge back under 11,000 Python lines.

## Consequences

The live-status, lanes and lookup work can land while the follow-up fixes reduce complexity.
This ceiling applies only to Forge's own repo. New client repos, including adoption, and existing
client repos on upgrade see no change. The module and command limits stay unchanged; another
ceiling raise needs an accepted decision.
