# Forge's Python cap is 10,000

## Context

Decision 0100 raised the cap to 8,500 lines on 2026-09-30. By 2026-10-01 Forge's Python stood at
8,437 lines, and five approved stories (one command to land a change, one command to upgrade,
doctor repairs, running all in Claude, Codex or both, and learning where code keeps breaking) each
add a few hundred lines. The first of them already failed review on the cap.

## Decision

The cap still counts only Python files under `src/forge`, and it is 10,000. The owner chose this on
2026-10-01 together with one trim pass in parallel that removes dead or duplicated code, over
trimming first at 8,500 and over a smaller raise to 9,000.

## Consequences

- Room for the five approved stories; each task still keeps its own code lean.
- A trim fix runs alongside and should give back at least 300 lines.
- The 1,200-line module limit and the command limit are unchanged.
- Raising the cap again still needs an accepted decision.
