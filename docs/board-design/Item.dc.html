Pull requests take in main only on a real clash

What changes for you

  • A pull request takes in main only when main changed a file it also changes.
  • A merge to main no longer forces a fresh review on every open change.
  • Spotted problems are kept per change, not lost in the merge.

Done when

  1. A change with no shared file merges without taking in main.
  2. A change that shares a file takes in main once, then reviews once.
  3. Each change keeps its own spotted problems through an upgrade.
